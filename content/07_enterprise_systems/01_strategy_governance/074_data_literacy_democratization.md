## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 데이터 리터러시 민주화는 조직 구성원이 데이터를 읽고 해석하고 활용하도록 하는 전략이다.
> 2. **가치**: 데이터 기반 의사결정을 전사로 확산한다.
> 3. **판단**: 도구 제공만이 아니라 교육과 문화가 필요하다.

---

## Ⅰ. 개요 및 필요성

데이터가 있어도 읽지 못하면 의미가 없다.

그래서 리터러시가 중요하다.

- **📢 섹션 요약 비유**: 책이 있어도 글을 읽을 수 있어야 하는 것과 같다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Data
  v

```

| 요소 | 의미 |
| :-- | :-- |
| Literacy | 읽고 해석 |
| Democratization | 모두에게 개방 |

데이터 민주화는 일부 전문가만이 아니라 조직 전체가 데이터를 활용하는 상태다.

- **📢 섹션 요약 비유**: 모두가 지도를 읽을 수 있게 하는 것이다.

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 데이터 교육이 있는가?
2. 셀프서비스가 가능한가?
3. 용어가 통일되어 있는가?
4. 책임과 권한이 명확한가?
5. 데이터 문화가 있는가?

### 안티패턴

- 도구만 배포하는 설계
- 교육 없이 민주화만 외치는 설계
- 데이터 해석을 일부에게만 맡기는 설계
- 지표 정의가 없는 설계

실무 관점에서는 데이터 리터러시 민주화를 "조직의 데이터 해석 능력 확산"으로 설명해야 한다.

- **📢 섹션 요약 비유**: 모두가 숫자 이야기를 이해하게 만든다.

## Ⅴ. 기대효과 및 결론

데이터 리터러시가 높아지면 의사결정 속도와 품질이 좋아진다.

- **📢 섹션 요약 비유**: 모두가 같은 지도를 보고 길을 찾는다.
