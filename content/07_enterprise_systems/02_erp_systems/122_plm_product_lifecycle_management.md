## 핵심 인사이트 (3줄 요약)
> 1. **본질**: PLM은 제품의 <strong>기획->설계->제조->서비스->폐기까지 전 생명주기에 걸친 데이터·프로세스·사람을 통합 관리</strong>하는 엔터프라이즈 시스템이다.
> 2. **가치**: CAD 도면·BOM(부품 목록)·변경 이력·품질 데이터가 부서별로 분산되면 <strong>설계 변경 누락·부품 불일치·품질 사고</strong>가 발생하지만, PLM이 <strong>단일 제품 데이터 허브</strong>를 제공하여 전사 협업을 보장한다.
> 3. **판단 포인트**: PLM은 ERP(생산·재무)·MES(제조 실행)·SCM(공급망)과 통합되어 <strong>제품 중심 디지털 스레드(Digital Thread)</strong>를 구성하며, 디지털 트윈의 데이터 원천이 된다.

---

## Ⅰ. 개요 및 필요성

```text
+-------------------------------------------------------+
|    PLM이 관리하는 제품 전주기                          |
+-------------------------------------------------------+
|  기획 -> 설계(CAD) -> 시뮬레이션(CAE) -> 제조(CAM)     |
|     -> 품질관리 -> 서비스·유지보수 -> 폐기·재활용      |
|                                                       |
|  PLM 관리 대상:                                       |
|   - CAD 도면·3D 모델                                 |
|   - BOM (Bill of Materials, 부품 목록)               |
|   - ECO (Engineering Change Order, 설계 변경)        |
|   - 품질·시험 데이터                                 |
+-------------------------------------------------------+
```

- **📢 섹션 요약 비유**: PLM은 제품의 <strong>출생(기획)부터 사망(폐기)</strong>까지의 모든 기록을 보관하는 전자 건강 기록부다.

---

## Ⅱ. 아키텍처 및 핵심 원리

### PLM 핵심 기능

| 기능 | 설명 |
|:---|:---|
| **CAD 관리** | 도면·3D 모델 버전 관리 |
| <strong>BOM 관리</strong> | 부품 구성 트리, E-BOM/M-BOM |
| <strong>변경 관리</strong> | ECR->ECO->ECN 워크플로 |
| **프로젝트 관리** | 제품 개발 일정·마일스톤 |
| **품질 관리** | FMEA·CAPA 연동 |

- **📢 섹션 요약 비유**: BOM은 요리 레시피(재료 목록)이고, ECO는 레시피 변경 승인 절차다.

---

## Ⅲ. 비교 및 연결

| 비교 | PLM | ERP | MES |
|:---|:---|:---|:---|
| **관점** | <strong>제품 데이터</strong> | 경영·재무 | 제조 실행 |
| **단계** | 설계~폐기 | 계획~재무 | 생산 현장 |
| <strong>데이터</strong> | CAD·BOM·ECO | 주문·재고·원가 | 실적·품질 |

---

## Ⅳ. 실무 적용 및 실무자 판단

### Digital Thread
PLM->ERP->MES->서비스를 관통하는 제품 데이터의 연속적 흐름으로, 설계 변경이 제조·서비스에 즉시 반영된다.

---

## Ⅴ. 기대효과 및 결론

PLM은 <strong>제조업 DX(디지털 전환)의 핵심 축</strong>이며, 디지털 트윈·AI 시뮬레이션과 결합하여 제품 개발 기간을 30~50% 단축하고 있다.
