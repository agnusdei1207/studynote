## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 일회용 패드는 평문과 같은 길이의 완전한 난수 키를 한 번만 사용하는 암호 방식이다.
> 2. **가치**: 이론적으로 완전 비밀성을 제공한다.
> 3. **판단**: 키 관리가 극도로 어려워 실무 적용이 제한적이다.

---

## Ⅰ. 개요 및 필요성

암호학에서 가장 강한 이론적 보안이 필요할 때 등장하는 방식이다.

하지만 현실적으로 쓰기 어렵다.

- **📢 섹션 요약 비유**: 한 번 쓰고 버리는 완벽한 비밀 쪽지다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Plaintext + Random Key
  v
Ciphertext
```

| 조건 | 의미 |
| :-- | :-- |
| Random Key | 완전 난수 |
| Same Length | 같은 길이 |
| One-time Use | 1회 사용 |

키가 진짜 난수이고 한 번만 사용되면 공격자가 정보를 얻기 어렵다.

- **📢 섹션 요약 비유**: 매번 새로 만든 비밀 코드다.

---

## Ⅲ. 비교 및 연결

| 방식 | 보안 | 실무성 |
| :-- | :-- | :-- |
| One-Time Pad | 매우 높음 | 낮음 |
| Modern Cryptography | 높음 | 높음 |

| 핵심 | 의미 |
| :-- | :-- |
| Perfect Secrecy | 완전 비밀성 |
| Key Distribution | 키 분배 |

OTP는 이론적으로는 최강이지만 키 분배 문제가 크다.

- **📢 섹션 요약 비유**: 열쇠가 너무 완벽해서 관리가 힘든 금고다.

---

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 난수가 정말 완전한가?
2. 키 길이가 평문과 같은가?
3. 키를 한 번만 쓰는가?
4. 키 분배가 가능한가?
5. 이론과 실무를 구분하는가?

### 안티패턴

- 키 재사용
- 난수 품질이 낮은 경우
- 키 관리 없이 실무 적용
- OTP를 현대 암호와 동일시하는 설계

실무 관점에서는 OTP를 "이론적으로 완전 비밀성을 보이는 암호"로 설명해야 한다.

- **📢 섹션 요약 비유**: 한 번 쓰는 완벽한 비밀 열쇠다.

---

## Ⅴ. 기대효과 및 결론

OTP는 암호학의 기준점을 제시한다.

결론적으로 일회용 패드는 완전 난수 키를 한 번만 쓰는 이론적 완전비밀 암호다.

- **📢 섹션 요약 비유**: 완벽하지만 너무 까다로운 비밀 방식이다.
