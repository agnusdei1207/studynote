## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Cumulative Flow Diagram (CFD)은 칸반에서 상태별 작업 누적을 시간축으로 보여 주는 시각화다.
> 2. **가치**: WIP (Work In Progress)와 병목을 동시에 보여 줘 흐름 정체를 빨리 찾게 해 준다.
> 3. **판단 포인트**: 완료량보다 띠의 두께와 기울기를 읽어야 예측 가능성을 판단할 수 있다.

---

## Ⅰ. 개요 및 필요성
CFD는 “얼마나 많이 했는가”보다 “어디서 막히는가”를 본다. 작업이 상태별로 쌓이는 면적을 보므로, 완료 숫자가 비슷해도 특정 상태의 띠가 두꺼워지면 이상 신호를 잡을 수 있다.

그래서 스프린트 종료용 차트보다 흐름 관리에 더 가깝다.
- **📢 섹션 요약 비유**: 쌓인 모양을 보면 흐름이 보인다.

---

## Ⅱ. 아키텍처 및 핵심 원리
| 요소 | 의미 | 읽는 법 |
|:---|:---|:---|
| 시간축 | 관찰 시점 | 왼쪽에서 오른쪽 |
| 누적 면적 | 상태별 작업 수 | 위로 갈수록 완료에 가까움 |
| 띠 두께 | 해당 상태의 WIP | 두꺼울수록 체류가 많음 |
| 상단 곡선 | 총 흐름 | 기울기 변화가 처리량 변화 |

+---------------- CFD 예시 ----------------+
| 완료  ████████████████████████████████    |
| 검증  ████████████████████                |
| 개발  ██████████                          |
| 대기  ███                                 |
+-------------------------------------------+
         t1        t2        t3        t4
- **📢 섹션 요약 비유**: 띠의 두께가 곧 체류량이다.

---

## Ⅲ. 비교 및 연결
| 비교 항목 | CFD | Burndown Chart | Kanban Board | Gantt Chart |
|:---|:---|:---|:---|:---|
| 주 목적 | 흐름과 병목 관찰 | 남은 작업 감소 | 현재 상태 관리 | 일정 관리 |
| 강점 | WIP 변화가 잘 보임 | 완료 추세가 직관적 | 협업이 쉬움 | 기간 추적에 강함 |
| 한계 | 해석에 익숙해야 함 | 상태별 정체를 숨김 | 시간 누적이 약함 | 흐름 병목을 직접 못 봄 |

CFD는 다른 보드와 경쟁하는 도구가 아니라, 흐름 관리에 특화된 보완 도구다.
- **📢 섹션 요약 비유**: CFD는 칸반의 병목을 보는 눈이다.

---

## Ⅳ. 실무 적용 및 실무자 판단
- [ ] 상태 정의를 일관되게 유지한다.
- [ ] WIP 제한이 실제로 지켜지는지 확인한다.
- [ ] 띠가 두꺼워지는 구간을 병목 후보로 본다.
- [ ] 평균 처리량만 보지 말고 분산과 체류시간도 본다.

- ❌ 특정 시점 한 줄만 보고 전체 흐름을 단정하는 것
- ❌ 완료/대기/차단 상태를 섞어 집계하는 것
- ❌ 대기열이 늘어나는데 사람 수만 늘리려는 것
- **📢 섹션 요약 비유**: 완료 숫자보다 병목 구간을 먼저 본다.

---

## Ⅴ. 기대효과 및 결론
CFD는 작업의 양보다 흐름의 안정성을 보여 준다. 그래서 병목을 숫자가 아니라 모양으로 읽게 해 준다.
- **📢 섹션 요약 비유**: 흐름이 보이면 예측도 쉬워진다.

### 📌 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| CFD | 상태별 누적 흐름을 보여 준다. |
| WIP (Work In Progress) | 현재 막혀 있는 작업량이다. |
| Kanban | 상태 정의의 기반이다. |
| Lead Time | 고객이 체감하는 대기 시간이다. |
| Cycle Time | 실제 처리 시간을 본다. |

### 📈 관련 키워드 및 발전 흐름도

```text
입력 증가 -> 상태별 누적 집계 -> 띠 두께 관찰 -> 병목 탐지 -> WIP 조정 -> 흐름 재측정
```

### 👶 어린이를 위한 3줄 비유 설명

1. 책상 위 연습장 더미를 보면, 어떤 과목이 많이 남았는지 바로 알 수 있다.
2. 한쪽 더미만 두꺼워지면 그 과목이 막히고 있다는 뜻이다.
3. 줄이 길어지는 곳을 보면, 어디를 넓혀야 하는지 알 수 있다.
