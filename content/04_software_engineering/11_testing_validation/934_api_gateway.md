## 핵심 인사이트 (3줄 요약)

> 1. **본질**: API 게이트웨이 (API Gateway) - 인증, 라우팅, 로드밸런싱, 통합(Aggregation)은(는) 소프트웨어 공학의 핵심 개념으로, 복잡한 시스템을 체계적으로 설계·관리하기 위한 원칙과 기법이다.
> 2. **가치**: 이 개념을 올바르게 적용하면 소프트웨어의 품질·유지보수성·재사용성이 향상되고, 개발 생산성과 팀 협업 효율이 높아진다.
> 3. **판단 포인트**: 도입 시에는 비용·복잡도·조직 성숙도를 함께 고려해야 하며, 맹목적 적용보다 프로젝트 특성에 맞는 선택적 적용이 핵심이다.

---

## Ⅰ. 개요 및 필요성

마이크로서비스가 많아질수록 클라이언트가 각 서비스를 직접 호출하기 어렵다. API 게이트웨이는 앞단에서 요청을 받아 적절한 서비스로 전달한다.

- **📢 섹션 요약 비유**: 건물 현관의 안내데스크가 방문 목적에 따라 사람을 배정하는 것과 같다.

---

다음은 API 게이트웨이 (API Gatew의 핵심 구조와 흐름을 보여주는 다이어그램이다.

```text
+-------------------------------------------------------------+
|                  API 게이트웨이 (API Gatew                        |
+-------------------------------------------------------------+
|                                                             |
|  [입력/요구사항] ---> [핵심 처리 과정] ---> [출력/결과물]  |
|       |                    |                    |          |
|       v                    v                    v          |
|   요구 분석           설계·적용           품질 검증        |
|                                                             |
+-------------------------------------------------------------+
```

이 다이어그램은 API 게이트웨이 (API Gatew가 입력 요구사항을 받아 핵심 처리 과정을 거쳐 검증된 결과물을 산출하는 흐름을 보여준다.

## Ⅱ. 아키텍처 및 핵심 원리

게이트웨이는 인증 확인, 경로 선택, 응답 조합, 요청 제한을 수행할 수 있다.

```text
Client -> API Gateway -> Service A
                     -> Service B
                     -> Service C
```

| 기능 | 설명 |
|:---|:---|
| Authentication | 인증 확인 |
| Routing | 서비스 분기 |
| Aggregation | 응답 통합 |
| Rate Limiting | 과도한 호출 제어 |

- **📢 섹션 요약 비유**: 입구에서 신분 확인하고, 갈 곳을 안내하고, 필요한 서류를 묶어 주는 창구다.

## Ⅲ. 비교 및 연결

API 게이트웨이는 BFF (Backend For Frontend)와 연계되기도 하고, 서비스 메시(Service Mesh)와 역할을 나눌 수도 있다. 클라이언트가 직접 내부 서비스를 아는 것보다 훨씬 단순해진다.

| 구분 | 직접 호출 | API Gateway |
|:---|:---|:---|
| 클라이언트 복잡도 | 높음 | 낮음 |
| 공통 정책 | 분산 | 집중 |
| 운영 통제 | 낮음 | 높음 |

- **📢 섹션 요약 비유**: 각 방 문을 다 외우는 대신 현관 한 곳만 기억하면 된다.

## Ⅳ. 실무 적용 및 실무자 판단

실무에서는 인증과 라우팅이 지나치게 비대해지지 않도록 주의하고, 캐시와 타임아웃으로 지연을 관리한다.

점검 포인트는 다음과 같다.
1. 게이트웨이가 병목이 되지 않는가?
2. 정책 변경이 배포 없이 가능한가?
3. 내부 서비스가 외부에 노출되지 않는가?

- **📢 섹션 요약 비유**: 문지기가 너무 많은 일을 맡으면 현관이 막힌다.

## Ⅴ. 기대효과 및 결론

API 게이트웨이는 공통 관심사를 한곳에 모아 운영을 단순화한다.

- **📢 섹션 요약 비유**: 집에 들어가기 전에 안내받는 정문이다.
