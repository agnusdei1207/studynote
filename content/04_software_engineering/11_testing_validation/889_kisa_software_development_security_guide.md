## Ⅰ. 개요 및 필요성

행정안전부와 KISA (Korea Internet & Security Agency)는 안전한 소프트웨어 개발을 위한 가이드를 제시한다.

현장에서 가장 중요한 건 체크리스트를 외우는 게 아니라, 개발 과정에 녹여 넣는 것이다.

- **📢 섹션 요약 비유**: 학교에서 안전수칙을 붙여 두는 것처럼, 개발에도 기본 규칙이 필요하다.

- **📢 섹션 요약 비유**: 약속만 적은 종이가 아니라, 실제 생활 규칙이어야 한다.

### 📌 관련 개념 맵

| 개념 | 연결 포인트 |
| :--- | :--- |
| 소프트웨어 공학 (Software 엔진ering) | 행정안전부/KISA 소프트웨어 개발 보안 가이드의 상위 학문 체계이며 품질·생산성 향상의 공통 목표를 공유한다 |
| 소프트웨어 생명주기 (SDLC, Software Development Life Cycle) | 행정안전부/KISA 소프트웨어 개발 보안 가이드은 SDLC의 특정 단계에서 핵심적으로 적용된다 |
| 품질 보증 (QA, Quality Assurance) | 행정안전부/KISA 소프트웨어 개발 보안 가이드 적용 결과는 QA 활동을 통해 검증되고 측정된다 |
| 형상 관리 (SCM, Software Configuration Management) | 행정안전부/KISA 소프트웨어 개발 보안 가이드에서 생성된 산출물은 SCM을 통해 체계적으로 관리된다 |

### 📈 관련 키워드 및 발전 흐름도

```text
소프트웨어 위기 (Software Crisis) 인식
    |
    v
행정안전부/KISA 소프트웨어 개발 보안 가이드 개념 정립
    |
    v
표준화 및 방법론 체계화 (ISO, CMMI, Agile)
    |
    v
클라우드 네이티브·AI 기반 확장 적용
    |
    v
지속적 개선 및 DevOps·MLOps 통합
```

이 흐름은 소프트웨어 위기 인식 -> 체계적 방법론 개발 -> 표준화 -> 현대적 플랫폼 적용으로 이어지는 발전 과정을 보여준다.

### 👶 어린이를 위한 3줄 비유 설명

1. 행정안전부/KISA 소프트웨어 개발 보안 가이드은 레고 블록으로 성을 만들 때처럼, 규칙을 정하고 역할을 나누어 함께 작업하는 방법이에요.
2. 혼자서 막 만들면 나중에 무너지거나 고치기 어렵지만, 약속을 지키면 누구나 쉽게 고치고 더 크게 만들 수 있어요.
3. 그래서 소프트웨어 공학은 프로그래머들이 좋은 프로그램을 빠르고 안전하게 만들 수 있게 도와주는 '규칙 모음집'이에요.
