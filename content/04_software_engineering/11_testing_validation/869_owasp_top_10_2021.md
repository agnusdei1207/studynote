## 핵심 인사이트 (3줄 요약)

> 1. **본질**: OWASP Top 10 (2021)은(는) 소프트웨어 공학의 핵심 개념으로, 복잡한 시스템을 체계적으로 설계·관리하기 위한 원칙과 기법이다.
> 2. **가치**: 이 개념을 올바르게 적용하면 소프트웨어의 품질·유지보수성·재사용성이 향상되고, 개발 생산성과 팀 협업 효율이 높아진다.
> 3. **판단 포인트**: 도입 시에는 비용·복잡도·조직 성숙도를 함께 고려해야 하며, 맹목적 적용보다 프로젝트 특성에 맞는 선택적 적용이 핵심이다.

## Ⅰ. 개요 및 필요성

OWASP (Open Worldwide Application Security Project) Top 10은 웹 애플리케이션에서 많이 발생하는 위험을 정리한 목록이다. 보안 교육과 점검 기준으로 널리 쓰인다.

새로운 팀이 보안을 시작할 때 최소한의 공통 언어가 되어 준다.

- **📢 섹션 요약 비유**: 비 오는 날 우산, 미끄럼, 감기부터 챙기는 생활 안전 수첩과 같다.

## Ⅱ. 아키텍처 및 핵심 원리

OWASP Top 10은 특정 제품의 취약점이 아니라, 넓게 반복되는 위험 범주를 다룬다.

```text
웹 입력
  -> 인증/권한
  -> 데이터 처리
  -> 로그/오류
  -> 외부 연동
  -> 위험 범주 점검
```

| 특징 | 의미 |
|:---|:---|
| 범용성 | 많은 웹 서비스에 적용 가능 |
| 우선순위 | 자주 발생하는 위험 중심 |
| 교육성 | 팀 공통 기준으로 좋음 |

- **📢 섹션 요약 비유**: 자주 넘어지는 계단에 먼저 손잡이를 다는 것과 같다.

## Ⅲ. 비교 및 연결

OWASP Top 10은 STRIDE, DREAD 같은 모델보다 더 실무 체크리스트에 가깝다.

| 구분 | OWASP Top 10 | STRIDE |
|:---|:---|:---|
| 형태 | 위험 목록 | 위협 분류 |
| 초점 | 웹 애플리케이션 | 보안 위협 범주 |
| 활용 | 보안 점검 기준 | 설계 분석 |

버전이 바뀌어도 "반복되는 실수"를 잡는다는 목적은 같다.

- **📢 섹션 요약 비유**: 시험 기출문제집은 문제 유형을 모아 주고, 개념서는 왜 그런지 설명해 준다.

## Ⅳ. 실무 적용 및 실무자 판단

실무에서는 코드 리뷰, 보안 진단, 교육, 요구사항 정의에 활용한다.

중요한 것은 목록을 외우는 것이 아니라, 내 서비스에 어떤 항목이 더 중요한지 해석하는 일이다.

1. 서비스 범위를 정한다.
2. 관련 위험 항목을 체크한다.
3. 우선순위와 대응책을 문서화한다.

- **📢 섹션 요약 비유**: 반찬 가게에서 다 먹는 메뉴가 아니라 오늘 필요한 재료부터 사는 것과 같다.

### 👶 어린이를 위한 3줄 비유 설명

1. OWASP Top 10 (2021)은 레고 블록으로 성을 만들 때처럼, 규칙을 정하고 역할을 나누어 함께 작업하는 방법이에요.
2. 혼자서 막 만들면 나중에 무너지거나 고치기 어렵지만, 약속을 지키면 누구나 쉽게 고치고 더 크게 만들 수 있어요.
3. 그래서 소프트웨어 공학은 프로그래머들이 좋은 프로그램을 빠르고 안전하게 만들 수 있게 도와주는 '규칙 모음집'이에요.
