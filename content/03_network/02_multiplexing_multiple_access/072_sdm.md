## 핵심 인사이트 (3줄 요약)

> 1. **본질**: SDM은 공간을 분리해 여러 신호를 동시에 전송하는 다중화 방식이다.
> 2. **가치**: 물리적으로 분리된 경로를 활용해 간섭을 줄이고 용량을 높인다.
> 3. **판단**: Massive MIMO 같은 다중 안테나 기술과 함께 이해해야 한다.

---

## Ⅰ. 개요 및 필요성

주파수나 시간만 나누는 것으로는 한계가 있다. 공간 자체를 나누면 더 많은 채널을 만들 수 있다.

그래서 SDM이 중요하다.

- **📢 섹션 요약 비유**: 같은 방이라도 칸막이를 치면 여러 사람이 동시에 쓸 수 있다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Spatial Paths
  v separated channels
Parallel Transmission
```

| 요소 | 의미 |
| :-- | :-- |
| Spatial Separation | 공간 분리 |
| Antenna Array | 다중 안테나 |
| Channel Isolation | 간섭 감소 |

SDM은 물리적 공간이나 안테나 배열을 이용해 신호를 분리한다.

- **📢 섹션 요약 비유**: 여러 문을 따로 만들어 줄을 나누는 것이다.

---

## Ⅲ. 비교 및 연결

| 방식 | 기준 | 특징 |
| :-- | :-- | :-- |
| TDM | 시간 | 순차 |
| FDM | 주파수 | 대역 분리 |
| SDM | 공간 | 물리 분리 |

| 연결 | 의미 |
| :-- | :-- |
| MIMO | 다중 안테나 |
| Massive MIMO | 대규모 공간 다중화 |

SDM은 무선 용량 확장과 간섭 제어를 위해 중요하다.

- **📢 섹션 요약 비유**: 같은 자리에 여러 길을 따로 만드는 것이다.

---

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 공간 분리 조건이 있는가?
2. 다중 안테나를 활용하는가?
3. 간섭 감소를 설명할 수 있는가?
4. Massive MIMO와 연결되는가?
5. 회선/무선 환경을 구분하는가?

### 안티패턴

- 공간 분할을 단순한 케이블 분리로 보는 설계
- MIMO와 SDM을 구분하지 않는 설계
- 간섭 제어를 무시하는 설계
- 물리적 분리를 고려하지 않는 설계

실무 관점에서는 SDM을 "공간 자원 기반 다중화"로 설명해야 한다.

- **📢 섹션 요약 비유**: 방을 여러 칸으로 나눠 동시에 쓰는 방식이다.

---

## Ⅴ. 기대효과 및 결론

SDM은 공간을 활용해 전송 용량을 높인다.

결론적으로 SDM은 물리적 공간을 분리해 여러 신호를 동시에 보내는 방식이다.

- **📢 섹션 요약 비유**: 공간을 나누면 동시에 더 많이 보낼 수 있다.
