## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 시계열 분석은 시간에 따라 순차적으로 관측된 데이터의 자기상관성(Autocorrelation), 정상성(Stationarity), 계절성(Seasonality)을 수학적 확률 과정(Stochastic Process)으로 모델링하여 미래를 예측하는 통계·기계학습 기법으로, ARIMA(p,d,q)는 AR(자기회귀)·I(차분)·MA(이동평균)의 Box-Jenkins 선형 결합 구조를 따르고, Prophet은 이를 가법 분해 모델 $y(t) = g(t) + s(t) + h(t) + \epsilon_t$로 비선형 트렌드 + 푸리에 급수 기반 다중 계절성 + 휴일 효과로 일반화한 구조이다.
> 2. **가치**: MAPE 5~15% 수준 내의 비즈니스 KPI 예측 정확도 확보, 결측치·이상치·변동점(Changepoint)에 강건한 자동 예측 파이프라인 구축을 통해 수동 Forecast 대비 80% 이상의 분석 공수 절감, 그리고 SARIMAX 외생변수 결합 및 Prophet의 다중 계절성(주/연/사용자 정의) 모델링으로 단일 모델로는 불가능했던 복합 시계열 통합 예측이 가능하다.
> 3. **판단 포인트**: 데이터 표본(≥100 obs), 정상성 만족 여부(ADF/KPSS 검정), 시계열의 주기적 패턴 강도, 외생변수 유무, 해석 가능성 vs 예측 정확도 트레이드오프, 그리고 단기(≤30일)에는 SARIMA·ETS가, 장기·다중계절성·휴일 효과에는 Prophet·TFT가 유리하다는 모델 선택 기준을 명확히 해야 한다.

## Ⅰ. 개요 및 필요성

시계열(Time Series) 데이터는 금융 시세, IoT 센서 로그, 웹 트래픽, 매장 매출, 전력 부하, 재고 회전율, 호출량(Call Volume), SRE 관측 지표(MTTR, Apdex) 등 현대 정보시스템의 거의 모든 운영·비즈니스 영역에서 발생하는 **순서가 의미를 갖는 순차 데이터(Sequential Data)**이다. 일반적인 독립동일분포(i.i.d.) 가정의 회귀·분류 모델로는 시간의 흐름에 따른 자기상관 구조와 계절·추세·휴일 같은 캘린더 효과를 반영할 수 없으므로, 별도의 시계열 모델링 체계가 요구된다.

특히 2020년 COVID-19로 인한 수요 충격, 2022년 메타·트위터 등 글로벌 서비스의 트래픽 패턴 변동, 그리고 다변량 클라우드 워크로드 예측 등에서 **기존의 단순 이동평균·지수평활(ETS) 모델은 한계**를 드러냈다. 이에 따라 (1) 통계적 정상성 변환을 통해 자기회귀 구조를 학습하는 **ARIMA/SARIMA 계열**, (2) 비선형 트렌드·휴일 효과·다중 계절성을 자동 분해하는 **Prophet(2017, Facebook)**, (3) RNN/LSTM 기반의 **DeepAR, N-BEATS, TFT(2021)**, (4) Transformer 기반의 **Informer, Autoformer, PatchTST**로 이어지는 진화적 흐름이 정착되었다.

실무적 관점에서 시계열 예측은 **"데이터의 시계열적 특성을 정확히 진단" -> "정상성·계절성·변동점 기반 모델 선택" -> "교차검증과 잔차 진단을 통한 모델 검증" -> "운영 환경에 맞춘 재학습 파이프라인 설계"**의 4단계를 밟아야 하는 시스템 엔지니어링 문제이며, 단순히 라이브러리 호출이 아닌 **데이터 거버넌스, 모델 거버넌스, 비즈니스 KPI 연계**까지 포함하는 종합 의사결정 프레임워크가 필요하다.

기존 단순예측(평균·이동평균)은 **시간에 따라 변하는 분산(Variance)과 구조(Structure)를 반영하지 못하는 정적 모델**이었다. ARIMA는 이를 확률적 정상 과정(Stationary Stochastic Process)으로 일반화했고, Prophet은 캘린더 기반 휴일 효과와 piecewise linear/logistic 트렌드를 결합해 **도메인 전문가의 직관을 모델에 주입**할 수 있게 했다. 이후 Transformer·N-BEATS·TFT 같은 딥러닝 모델은 다변량(Multivariate), 다중수평(Multi-horizon), 확률적 예측(Probabilistic Forecasting)을 가능케 했다.

- **📢 섹션 요약 비유**: 시계열 예측은 "강물의 과거 수위 기록을 보고 다음 달 홍수를 예측하는 수문학자"의 작업과 같다. 단순 평균(Naive Forecast)은 "오늘 수위 = 어제 수위" 수준이지만, ARIMA는 "과거 7일의 흐름 + 계절별 강수 패턴 + 강우량"을 동시에 고려하고, Prophet은 "비·가뭄·댐 방류 같은 외부 이벤트 일정"까지 반영하는 정교한 예측 체계라고 보면 된다.

## Ⅱ. 아키텍처 및 핵심 원리

### 1) ARIMA 모델의 수학적 구조

ARIMA(p, d, q)는 비정상 시계열을 $d$회 차분하여 정상화한 뒤, AR(p)와 MA(q) 두 가지 선형 필터를 결합한 모델이다. **Box-Jenkins 방법론**(1970)은 정상성 판정 -> 식별(p,q) -> 추정 -> 진단 -> 예측의 5단계를 따른다.

$$y_t' = c + \phi_1 y_{t-1}' + \phi_2 y_{t-2}' + \dots + \phi_p y_{t-p}' + \theta_1 \epsilon_{t-1} + \dots + \theta_q \epsilon_{t-q} + \epsilon_t$$

여기서 $y_t' = \Delta^d y_t$는 $d$차 차분값, $\phi_i$는 AR 계수(자기회귀), $\theta_j$는 MA 계수(이동평균), $\epsilon_t \sim N(0, \sigma^2)$는 백색잡음(White Noise)이다. 이 모델은 **AR(자기회귀) 다항식** $\Phi(B) = 1 - \phi_1 B - \dots - \phi_p B^p$과 **MA 다항식** $\Theta(B) = 1 + \theta_1 B + \dots + \theta_q B^q$의 후방천이(Backshift) 연산자 $B$ 표현 $\Phi(B)(1-B)^d y_t = \Theta(B) \epsilon_t$로 일반화된다.

**계절성 ARIMA인 SARIMA(p,d,q)(P,D,Q)s**는 여기에 계절 주기 $s$(월별 12, 주별 52/7, 일별 7 등)와 계절 AR(P)·MA(Q)·차분(D)을 더해 표현한다:
$$\Phi_P(B^s) \phi(B) (1-B^s)^D (1-B)^d y_t = \Theta_Q(B^s) \theta(B) \epsilon_t$$

**외생변수 결합 SARIMAX**는 $y_t = \beta x_t + \text{SARIMA residual}$ 형태로 가격·프로모션·날씨 같은 공변량을 포함해 인과적 해석력을 높인다.

### 2) Prophet의 가법 분해 구조

Prophet은 **합성분 기반 비선형 회귀 모델**로, 원래의 시계열을 다음 4가지 성분으로 분해한다:

$$y(t) = g(t) + s(t) + h(t) + \epsilon_t$$

- $g(t)$: **Trend**(추세) — `linear` 또는 `logistic` 성장 모델. 변동점(Changepoints)을 자동 감지해 piecewise 구조로 표현.
- $s(t)$: **Seasonality**(계절성) — 푸리에 급수(Fourier Series)로 표현되는 주기함수: $s(t) = \sum_{n=1}^{N} \left( a_n \cos\frac{2\pi nt}{P} + b_n \sin\frac{2\pi nt}{P} \right)$.
- $h(t)$: **Holidays**(휴일/이벤트 효과) — 사용자 정의 휴일 목록에 대해 indicator 변수와 회귀 계수를 학습.
- $\epsilon_t$: 잔차(오차) — 일반적으로 정규분포로 가정.

핵심 아이디어는 **STL(Seasonal-Trend decomposition using LOESS)** 분해를 베이esian 회귀로 재해석한 것으로, L-BFGS 최적화로 MAP 추정을 수행한다.

### 3) 핵심 하이퍼파라미터

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **ARIMA 차수 (p, d, q)** | 시계열의 자기회귀·차분·이동평균 구조를 정의 | `p`는 PACF의 마지막 유의 lag, `q`는 ACF의 마지막 유의 lag, `d`는 ADF 검정으로 결정. `pmdarima.auto_arima`는 AICc 최소화 + 단계적 탐색. 과적합 방지를 위해 AIC/BIC를 비교하며, 일반적으로 $p+q \leq 5$ 권장. |
| **SARIMA 계절 차수 (P,D,Q,s)** | 계절 주기성 모형화 | `s`는 데이터의 계절 주기(7=주간, 12=월간, 24=일간-시간, 52=주간-년). `seasonal=True`로 pmdarima auto-ARIMA가 탐지. 다중계절성(예: 주간+연간) 지원 안 됨 -> Prophet/TFT 권장. |

| **Prophet Seasonality** | 다중·비대칭 계절성 모델링 | `yearly_seasonality`, `weekly_seasonality`, `daily_seasonality` + `add
