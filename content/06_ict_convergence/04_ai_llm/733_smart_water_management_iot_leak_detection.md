# 733. 스마트 물관리 IoT 누수 탐지 수질 (Smart Water Management IoT Leak Detection)

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 상수관망에 **DMA(District Metered Area)·유량·수압·음향·수질** 센서를 다중화 배치하고 **MNF(최소야간유량)·압력파·음향상관분석·AI 이상탐지(Anomaly Detection)** 기법을 융합하여, 배·급수관의 누수·관로 파괴·수질 이상을 실시간으로 탐지하는 **Cyber-Physical Water Grid** 시스템.
> 2. **가치**: 한국 상수도 NRW(무수익수)율은 약 13~16%로 OECD 평균(15~20%) 대비 개선 중이나, 1톤당 누수 손실 비용을 약 200~500원/톤으로 환산 시 연간 약 1.2조 원의 잠재적 손실 절감 효과. 누수 1건 조기 탐지로 복구 비용 70% 절감, 단수 시간 80% 단축, 수질 이상 사전 차단으로 시민 안전 확보.
> 3. **판단 포인트**: 통신 기술(LoRaWAN vs NB-IoT vs LTE-M) 선택 시 **전송거리·전력소모·데이터율·심도(지하 1.5m 매설 깊이)** 간 트레이드오프, 그리고 **시계열 빅데이터 기반 False Alarm 최소화(<5%)**, **OTA 펌웨어 보안**, **센서 자가진단(Self-calibration)**, **관로 노후도 매핑(Asset Management)** 통합이 핵심 의사결정 사항.

## Ⅰ. 개요 및 필요성

전 세계 인구의 약 50%가 수자원 부족 상황에 직면하고 있으며, UN SDG 6(Clean Water and Sanitation) 및 2050 Net-Zero 정책의 핵심 인프라로 **스마트 워터 그리드(Smart Water Grid)** 가 부상하고 있습니다. 한국 환경부 통계에 따르면, 전국 상수도관망 총연장은 약 168,000km에 달하며 노후관(20년 이상)이 약 24%에 이릅니다. 이 관로에서 발생하는 **누수(Leakage)** 는 단순한 수량 손실을 넘어 **관로 파괴(Burst) -> 단수 -> 수질 오염(이차오염) -> 시민 안전사고 -> 사회적 비용** 의 연쇄 반응을 일으킵니다.

기존의 상수관망 관리는 **정기적 현장 순찰**(Patrolling), **음향탐사 차량**(Leak Noise Correlator), **단계시험법(Step Test)** 에 의존하여, ①탐지 지연(평균 1~6개월), ② 인력 의존, ③ 광역 관망 통합 분석 불가, ④ 수질 모니터링은 채수 후 실험실 분석(T+1일~T+3일) 의 한계를 보였습니다.

**IoT 기반 스마트 누수·수질 관리 시스템** 은 이 패러다임을 **사후 대응(Post-mortem) -> 실시간 선제 대응(Preemptive)** 으로 전환합니다. 4차 산업혁명 핵심기술인 **IoT·Edge AI·5G·디지털 트윈** 을 융합하여, 배·급수 전 과정에서 **①센서 레이어 -> ②통신 레이어 -> ③데이터 레이어 -> ④AI 분석 레이어 -> ⑤제어·대응 레이어** 의 5단 구조로 구현합니다.

특히 **수질 모니터링(IoT Water Quality Monitoring)** 은 단순한 트리거 알람(Threshold Alarms)을 넘어, **수계 다중점 잔류염소(Cl₂) 감시**, **pH·탁도·전기전도도(EC)·TOC·온도** 의 연속측정(Continuous Monitoring)을 통해 **관로 내 정체(Stagnation) 구간 식별 -> 수질 사고(붉은물, 미생물 재성장) 예방** 까지 가능하게 합니다.

### 1. 센서·디바이스 계층의 핵심 원리

**가. 유량 센서 (Flow Meter)**

- **전자기 유량계 (Electromagnetic Flow Meter, EMF)**: 패러데이 법칙(E = v × B × D) 적용. 관로 직경 50~2000mm, 정확도 ±0.3~0.5% FS, 누수 시점의 유량 증가를 검출.
- **초음파 유량계 (Ultrasonic Flow Meter)**: 도플러/Transit-Time 방식, 비접촉·무동력, 기존 관로 클램프(Clamp-on) 설치 가능. 가정 인입관(배관 경관 DN15~50mm)에 적합.
- **배터리기반 자기 유량계 (Battery-powered Magnetic)**: 6~10년 배터리 수명, 15분 간격 데이터 송신. AMI(Advanced Metering Infrastructure) 단말.

**나. 음향 누수 센서 (Acoustic Leak Sensor)**
누수 시 발생하는 **누수음(Leak Noise) 스펙트럼(20~5000Hz)** 을 포집·분석.

```
신호 모델: y(t) = s(t) + n(t) + i(t)
여기서 s(t) = 누수 신호 (지수감쇏 패턴, f₀ ~ 1/f)
      n(t)  = 배경소음 (펌프·밸브·교통)
      i(t)  = 간섭 (전력선 60Hz harmonics)
```

두 음향 센서 간 **Cross-Correlation(상관함수)** 으로 누수점 위치 산출:

```
        L
Δt = arg max R_xy(τ),   위치 = v × Δt + -
                                    2
여기서 v = 음속(약 1,200~1,500 m/s, 관 재질·직경 의존)
        L = 센서간 거리(m)
```

**다. 수압 센서 (Pressure Transducer)**
급격한 압력 강하(예: 1분 내 0.5barv)는 **관로 파괴(Burst)** 의 핵심 시그니처. **Pressure Transient Analysis** (Joukowsky 수격 해석)와 결합.

**라. 수질 센서 (Water Quality Sensor)**
- **잔류염소(Cl₂)**: DPD 비색법 또는 amperometric 센서, 측정범위 0~5mg/L, 정확도 ±0.05mg/L. **정체수(Stagnation Water)** 시 Cl₂ 감소 -> 미생물 재성장 위험.
- **pH/ORP**: 유리전극 방식, 0~14pH, Nernst식(E = E₀ - 0.059·pH)
- **탁도(NTU)**: 90° 산란광 측정, 0~1000 NTU, ISO 7027 준용
- **전기전도도(EC)**: 4전극 방식, TDS 환산
- **TOC/DOC**: UV 254nm 흡광도 추정(개선된 UV254 -> TOC 모델식)
- **온도**: RTD Pt1000/DS18B20

### 3. AI 분석 계층의 핵심 알고리즘

**가. MNF(최소야간유량, Minimum Night Flow) 분석**
```
MNF_index = (Q_night / Q_avg) × 100
기준: MNF_index < 30% -> 정상
      30~50% -> 경미 누수 의심
      > 50%  -> 대규모 누수/Burst
구현: LSTM Autoencoder (입력: 7일×96쿼터 시계열, 손실: MSE, 임계: 95-percentile)
```

**나. 음향 누수 분류 CNN**
```
1D-CNN (입력: 5초 × 8kHz = 40,000 샘플, FFT 512)
+ Conv1D(64, kernel=8) -> ReLU -> MaxPool
+ Conv1D(128, kernel=4) -> ReLU -> MaxPool
+ LSTM(64, return_sequences=True)
+ Attention Layer
+ Dense(2, softmax) -> {Leak, NoLeak}
정확도: 95~98%, False Positive: < 5%
```

**다. 수질 이상탐지**
다변량 통계적 공정관리(MSPC)와 **Isolation Forest** 를 결합하여 다중
