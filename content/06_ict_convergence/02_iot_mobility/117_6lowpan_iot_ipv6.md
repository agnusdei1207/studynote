## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 6LoWPAN은 IEEE 802.15.4의 **127바이트 MTU 제약** 위에서 IPv6(최소 1280바이트 MTU)를 동작시키기 위해 <strong>헤더 압축·단편화·메시 라우팅</strong>을 수행하는 적응 계층이다.
> 2. **가치**: IoT 디바이스에 IPv6 주소를 부여하면 인터넷과 직접 통신이 가능하지만, 802.15.4의 작은 프레임에 IPv6 헤더(40바이트)를 넣으면 페이로드가 거의 없다. 6LoWPAN은 헤더를 <strong>2~7바이트로 압축</strong>하여 이 문제를 해결한다.
> 3. **판단 포인트**: Thread 프로토콜이 <strong>6LoWPAN을 적응 계층으로 사용</strong>하며, Matter의 저전력 전송 인프라의 핵심 기술이다.

---

## Ⅰ. 개요 및 필요성

```text
+-------------------------------------------------------+
|    6LoWPAN 헤더 압축                                  |
+-------------------------------------------------------+
|  [IPv6 헤더: 40바이트]                                |
|   + UDP 헤더: 8바이트 = 48바이트                      |
|   802.15.4 MTU: 127바이트                             |
|   -> 페이로드: 127 - 48 - MAC헤더 ≈ 50바이트뿐!      |
|                                                       |
|  [6LoWPAN 압축 후]                                    |
|   IPv6+UDP 헤더: 2~7바이트로 압축                     |
|   -> 페이로드: 100바이트 이상 확보!                    |
+-------------------------------------------------------+
```

- **📢 섹션 요약 비유**: IPv6 편지(40바이트 봉투)를 작은 엽서(127바이트 MTU)에 넣으려면 봉투를 접어야 한다. 6LoWPAN이 그 "접기 기술"이다.

---

## Ⅱ. 아키텍처 및 핵심 원리

### 6LoWPAN 핵심 기능

| 기능 | 설명 |
|:---|:---|
| <strong>헤더 압축 (IPHC)</strong> | IPv6 40B -> 2~7B 압축 (링크 로컬 주소 생략) |
| <strong>단편화 (Fragmentation)</strong> | 1280B IPv6 패킷 -> 127B 조각으로 분할 |
| <strong>메시 라우팅</strong> | 802.15.4 L2 메시 포워딩 |
| **NHC** | Next Header Compression (UDP 8B -> 2B) |

- **📢 섹션 요약 비유**: 6LoWPAN은 이사할 때 큰 가구(IPv6 패킷)를 분해(단편화)하고 포장 줄이기(압축)해서 작은 차(802.15.4 프레임)에 실는 기술이다.

## Ⅴ. 기대효과 및 결론

6LoWPAN은 "IoT 디바이스에 IPv6를 넣기 위한 필수 적응 기술"이며, Thread·Matter의 하위 계층으로서 스마트 홈 생태계의 기반 기술이다.

### 👶 어린이를 위한 3줄 비유 설명
1. IPv6 편지는 **봉투(40바이트)가 너무 커서** 작은 엽서(127바이트)에 안 들어가요.
2. 6LoWPAN은 봉투를 <strong>작게 접어서(압축)</strong> 엽서에 넣을 수 있게 해주는 기술이에요.
3. 이 기술 덕분에 아주 작은 센서도 <strong>인터넷(IPv6) 주소를 가지고</strong> 세상과 대화할 수 있답니다!
