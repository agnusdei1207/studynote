## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 분류 (Classification)는 과거의 데이터 패턴(입력 X)과 정답 레이블(출력 Y)의 관계를 학습하여, 새롭게 주어지는 미지의 데이터가 어떤 범주에 속하는지 예측하는 기계 학습(Machine Learning) 알고리즘이다.
> 2. **가치**: 스팸 메일 필터링, 신용카드 사기 탐지, 고객 이탈 예측 등 비즈니스에서 발생하는 "예/아니오" 또는 "다중 선택"의 의사결정을 인간의 개입 없이 빠르고 정확하게 자동화할 수 있다.
> 3. **판단 포인트**: 실무에서는 단일 알고리즘(로지스틱 회귀, 의사결정 나무 등)보다 예측 성능이 압도적인 앙상블 모델인 XGBoost (Extreme Gradient Boosting) 등을 기본으로 채택하되, 클래스 불균형 문제를 반드시 보정해야 한다.

---

## Ⅰ. 개요 및 필요성

분류 (Classification)는 인공지능 분야의 지도 학습(Supervised Learning) 중 가장 대표적인 문제 해결 방식이다. 연속적인 수치를 예측하는 회귀(Regression)와 달리, 분류는 데이터를 미리 정의된 불연속적인 범주(클래스)로 나누는 것이 목적이다.

현대의 비즈니스 환경에서는 매일 수백만 건의 텍스트, 이미지, 거래 데이터가 생성된다. 사람이 일일이 이 데이터가 정상인지 사기인지, 스팸인지 아닌지 판별하는 것은 물리적으로 불가능하다. 따라서 기계가 과거의 정답 데이터를 바탕으로 복잡한 비선형적 패턴을 학습하여 스스로 범주를 할당하는 분류 알고리즘의 도입이 필수적이다.

- **📢 섹션 요약 비유**: 분류는 베테랑 우체국 직원이 편지봉투의 특징(우편번호, 글씨체)만 보고도 수천 통의 편지를 각 동네 바구니(범주)로 1초 만에 휙휙 던져넣는 자동 분류 시스템과 같다.

## Ⅱ. 아키텍처 및 핵심 원리

분류 알고리즘은 데이터를 나누는 결정 경계(Decision Boundary)를 어떻게 형성하느냐에 따라 다양한 원리가 존재한다.

1. <strong>로지스틱 회귀 (Logistic Regression)</strong>:
   데이터의 선형 결합 결과를 시그모이드(Sigmoid) 함수에 통과시켜 0과 1 사이의 확률값으로 변환한다. 확률이 0.5 이상이면 클래스 1로 분류한다.
2. <strong>결정 트리 (Decision Tree)</strong>:
   특성(Feature) 값에 따라 스무고개 하듯 if-else 규칙 분기를 만든다. 노드를 나눌 때는 정보 이득(Information Gain)이 최대화되는 기준을 선택한다.
3. <strong>SVM (Support Vector Machine)</strong>:
   데이터를 범주로 나누는 가장 여백(Margin)이 넓은 최적의 초평면을 그린다. 커널 트릭(Kernel Trick)을 사용해 비선형 데이터도 분류할 수 있다.
4. <strong>앙상블 (Ensemble)</strong>:
   여러 개의 약한 분류기를 결합하여 강력한 분류기를 만드는 기법이다. 트리를 병렬로 만드는 랜덤 포레스트(Random Forest)나 순차적으로 오차를 보완하는 LightGBM (Light Gradient Boosting Machine)이 대표적이다.

```text
+-------------------------------------------------------------+
|                 [ 주요 분류 알고리즘의 결정 경계 ]          |
+-------------------------------------------------------------+
| 1. Logistic Regression      2. Decision Tree                |
|       |   ●   ●             | +-------+ +-------+         |
|     ● | ●   ●               | |   ●   | | ●   ● |         |
|  -----+-------- (선형)      | +-------+ +-------+ (계단형)|
|   ^   |   ^                 |   ^   +-------+             |
|   ^ ^|                     |   ^ ^|   ^   |             |
|                                                             |
| 3. SVM (Kernel Trick)       4. Ensemble (Random Forest)     |
|       |     ●               |    복수의 결정 트리가 다수결로  |
|    ●  (  ●    )  (비선형)   |    투표하여 가장 안정적이고   |
|   ^ ^  \   ●               |    복잡한 비선형 경계를 형성  |
|   ^   |   ^                 |                               |
+-------------------------------------------------------------+
```

알고리즘이 모델을 학습한 후에는 혼동 행렬(Confusion Matrix)을 통해 예측값과 실제 정답을 교차 검증하여 성능을 평가한다.

- **📢 섹션 요약 비유**: 분류 알고리즘은 면접관과 같다. 로지스틱 회귀는 엑셀 점수만 보는 딱딱한 면접관, 결정 트리는 꼬리에 꼬리를 무는 질문을 던지는 면접관, 앙상블은 100명의 면접관이 각자 점수를 매긴 뒤 다수결로 최종 합격을 결정하는 공정한 위원회다.

## Ⅲ. 비교 및 연결

분류 문제를 다룰 때는 단일 모델과 앙상블 모델의 명확한 트레이드오프를 비교해야 하며, 평가지표의 특성을 이해하는 것이 중요하다.

| 비교 항목 | 로지스틱 회귀 / 의사결정 나무 | 앙상블 (XGBoost, LightGBM) |
| :--- | :--- | :--- |
| **설명력 (해석 가능성)** | 우수 (가중치와 분기 규칙을 사람에게 설명 가능) | 낮음 (블랙박스화되어 결과 도출 과정 설명이 어려움) |
| <strong>성능 및 복잡도</strong> | 상대적으로 낮음 / 과적합 위험 높음 | 매우 높음 / 대용량 데이터에서 압도적인 정확도 |
| <strong>적용 도메인</strong> | 금융/의료 등 설명 책임이 규제로 강제되는 분야 | 이미지, 텍스트 분류 및 예측 정확도가 최우선인 분야 |

분류 성능을 평가할 때 정확도(Accuracy)만을 신뢰해선 안 된다. 전체의 99%가 정상 거래인 **클래스 불균형** 상황에서는 "모두 정상"으로만 찍어도 정확도가 99%가 나오기 때문이다. 이때는 정밀도(Precision), 재현율(Recall), F1 Score, 그리고 AUC-ROC (Area Under the Curve - Receiver Operating Characteristic) 지표를 함께 비교해야 한다.

- **📢 섹션 요약 비유**: 로지스틱 회귀는 이유를 명확하게 설명해주는 친절한 동네 의사라면, XGBoost는 이유는 설명 못 해도 병을 정확히 짚어내는 로봇 명의다. 병의 원인을 아는 게 중요하면 전자를, 당장 수술 여부를 맞추는 게 중요하면 후자를 써야 한다.

## Ⅳ. 실무 적용 및 실무자 판단

실무 현장에서 분류 모델을 설계하고 배포할 때 실무자로서 판단해야 할 핵심 요소는 다음과 같다.

1. **클래스 불균형 (Class Imbalance) 보정**:
   - 사기 탐지처럼 소수 클래스를 맞추는 것이 핵심일 경우, 합성 소수 표본 생성 기법인 SMOTE (Synthetic Minority Over-sampling Technique)를 쓰거나 알고리즘 내부에서 소수 클래스에 가중치를 주어야 한다.
2. **임계값 (Threshold) 튜닝**:
   - 분류기가 반환하는 확률의 기본 기준점은 0.5다. 하지만 암 환자를 놓치는 FN (False Negative)이 오진을 하는 FP (False Positive)보다 훨씬 치명적이라면, 이 기준점을 0.3으로 낮춰 의심되면 바로 환자로 분류하도록 전략적 조정을 해야 한다.
3. <strong>설명 가능한 인공지능 도입</strong>:
   - 앙상블 모델을 신용 심사에 쓸 경우 XAI (eXplainable Artificial Intelligence) 기법이 필요하다. SHAP (SHapley Additive exPlanations)이나 LIME (Local Interpretable Model-agnostic Explanations)을 결합하여 왜 분류되었는지 설명할 수 있어야 한다.

- **📢 섹션 요약 비유**: 화재경보기를 설치할 때, 알람이 안 울려 집이 타는 것이 무서우면 담배 연기만 나도 울리게 임계값을 예민하게 맞춰야 하고, 자꾸 울려서 잠을 깨는 것이 싫다면 진짜 불꽃이 보일 때만 울리도록 세팅해야 한다.

## Ⅴ. 기대효과 및 결론

분류 모델의 도입은 단순한 업무 자동화를 넘어 비즈니스의 선제적 방어 체계와 공격적 마케팅을 가능하게 한다.

하지만 데이터 분포가 시간에 따라 변하는 데이터 드리프트(Data Drift) 현상이 발생하면 성능은 급격히 하락한다. 결론적으로 훌륭한 분류 시스템은 한 번 만들고 끝나는 것이 아니라, 최신 데이터를 지속적으로 수집하고 모델을 재학습시키는 MLOps (Machine Learning Operations) 파이프라인과 함께 구축되어야 생명력을 얻는다.

- **📢 섹션 요약 비유**: 분류 시스템은 네비게이션과 같다. 처음엔 가장 빠른 길을 잘 분류해 알려주지만, 실시간으로 바뀌는 도로 통제 상황(새로운 데이터)을 업데이트하지 않으면 결국 막히는 옛날 길로 운전자를 안내하게 된다.
