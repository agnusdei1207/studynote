## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 비트는 정보를 표현하는 가장 작은 단위로 0과 1만 가진다.
> 2. **가치**: 디지털 시스템의 모든 데이터 표현은 비트에서 시작한다.
> 3. **판단**: 비트 수가 곧 표현 범위와 정밀도를 결정한다.

---

## Ⅰ. 개요 및 필요성

디지털 세계는 결국 0과 1로 표현된다. 그 기본 단위가 비트다.

그래서 모든 컴퓨터 구조의 출발점이다.

- **📢 섹션 요약 비유**: 전등 스위치처럼 켜짐과 꺼짐만 있는 가장 작은 단위다.

---

```text
0 / 1
  v
Bit
```

| 개념 | 의미 |
| :-- | :-- |
| Bit | 1비트 정보 |

비트는 논리, 저장, 통신, 연산의 공통 기초다.

- **📢 섹션 요약 비유**: 레고 블록 하나가 바로 비트다.

---

## Ⅲ. 비교 및 연결

| 단위 | 비트 수 | 의미 |
| :-- | :-- | :-- |
| Bit | 1 | 최소 정보 |
| Byte | 8 | 기본 저장 |
| Word | CPU 기준 | 연산 단위 |

| 관련 | 의미 |
| :-- | :-- |
| Binary | 2진수 |
| Capacity | 표현 범위 |

비트 수가 늘어날수록 표현 가능한 값이 늘어난다.

- **📢 섹션 요약 비유**: 작은 조각이 모여 큰 그림이 된다.

---

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 비트와 바이트를 구분하는가?
2. 비트 수가 범위를 결정함을 아는가?
3. 부호 비트를 설명할 수 있는가?
4. 데이터 표현과 연결하는가?
5. 네트워크/저장과도 연결하는가?

### 안티패턴

- 비트와 바이트를 혼동하는 설계
- 표현 범위를 무시하는 설계
- 이진 표현을 단순 숫자로만 보는 설계
- CPU word와 bit를 혼동하는 설계

실무 관점에서는 비트를 "디지털 정보의 최소 단위"로 설명해야 한다.

- **📢 섹션 요약 비유**: 모든 숫자의 시작점이다.

---

## Ⅴ. 기대효과 및 결론

비트를 이해하면 모든 데이터 표현을 더 정확하게 볼 수 있다.

결론적으로 비트는 0과 1로 정보를 표현하는 최소 단위다.

- **📢 섹션 요약 비유**: 디지털 세계의 가장 작은 벽돌이다.
