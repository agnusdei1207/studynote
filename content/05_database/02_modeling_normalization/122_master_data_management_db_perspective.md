## 핵심 인사이트 (3줄 요약)
> 1. **본질**: MDM은 고객·상품·조직·자산 등 <strong>핵심 마스터 데이터의 단일 골든 레코드(Golden Record)를 생성·유지</strong>하여, 전사 시스템(ERP·CRM·DW) 간 데이터 일관성과 품질을 보장하는 관리 체계다.
> 2. **가치**: 마스터 데이터가 시스템마다 다르면(고객명이 ERP="홍길동", CRM="길동 홍") <strong>보고서 불일치·중복 마케팅·재고 오류</strong>가 발생하며, MDM이 <strong>단일 진실 원천(Single Source of Truth)</strong>을 제공한다.
> 3. **판단 포인트**: Registry(참조형)·Consolidation(통합형)·Centralized(중앙 집중형)·Coexistence(공존형)의 4가지 구현 스타일을 구분하고, 데이터 거버넌스와의 연계가 핵심이다.

---

## Ⅰ. 개요 및 필요성

```text
+-------------------------------------------------------+
|    MDM 필요성                                         |
+-------------------------------------------------------+
|  [MDM 없음]                                           |
|   ERP: 고객ID=1001, 홍길동                           |
|   CRM: 고객ID=A99, 길동 홍                           |
|   DW: ???  -> 같은 사람? 다른 사람?                   |
|                                                       |
|  [MDM 적용]                                           |
|   MDM Hub: 고객 골든 레코드 = "홍길동, ID=M001"      |
|   ERP: M001 -> 홍길동 ✅                              |
|   CRM: M001 -> 홍길동 ✅                              |
|   -> 전사 일관된 고객 뷰                              |
+-------------------------------------------------------+
```

- **📢 섹션 요약 비유**: MDM은 전사 <strong>주민등록 시스템</strong>이다. 이름이 조금씩 다르게 적힌 주민을 하나의 정확한 레코드로 통합한다.

---

## Ⅱ. 아키텍처 및 핵심 원리

### MDM 구현 스타일

| 스타일 | 설명 | 적합 |
|:---|:---|:---|
| <strong>Registry</strong> | 기존 시스템에 참조 키만 매핑 | 낮은 침습성 |
| **Consolidation** | 읽기 전용 허브에 통합 | 분석·보고 |
| **Centralized** | MDM 허브가 유일한 원천 | <strong>최고 일관성</strong> |
| **Coexistence** | 허브 ↔ 시스템 양방향 동기 | 유연성 |

- **📢 섹션 요약 비유**: Registry는 전화번호부(참조만), Centralized는 중앙은행(모든 거래의 원천)이다.

## Ⅲ. 비교 및 연결

| 비교 | MDM 없음 | MDM 적용 |
|:---|:---|:---|
| <strong>데이터 일관성</strong> | 시스템별 상이 | **골든 레코드 통합** |
| **보고서** | 불일치 | **신뢰 가능** |
| **중복** | 빈번 | **제거** |

---

## Ⅳ. 실무 적용 및 실무자 판단

### MDM 구축 핵심 단계
1. <strong>프로파일링</strong>: 현행 데이터 품질 진단.
2. **매칭/병합**: 중복 레코드 식별·통합.
3. **골든 레코드**: 단일 마스터 생성.
4. **거버넌스**: 데이터 스튜어드 지정·정책 수립.

---

## Ⅴ. 기대효과 및 결론

MDM은 <strong>데이터 거버넌스의 기술적 구현체</strong>이며, CDP·데이터 메시·AI 학습 데이터 품질의 기반이 된다.

### 👶 어린이를 위한 3줄 비유 설명
1. MDM은 학교 <strong>출석부 관리 시스템</strong>이에요. 같은 학생이 다른 이름으로 등록되면 안 돼요.
