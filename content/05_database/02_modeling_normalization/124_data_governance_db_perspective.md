## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 데이터 거버넌스는 <strong>데이터의 가용성·무결성·보안·품질을 보장하기 위한 정책·프로세스·조직·기술의 통합 관리 체계</strong>이며, 데이터를 기업 자산으로 관리하는 전사적 프레임워크다.
> 2. **가치**: 거버넌스 없이는 데이터 중복·불일치·보안 사고·규제 위반이 발생하며, GDPR·개인정보보호법 등 <strong>규제 준수(Compliance)</strong>를 위해서도 필수적이다.
> 3. **판단 포인트**: DAMA-DMBOK이 데이터 관리 11개 영역을 정의하며, 데이터 스튜어드(Data Steward)가 도메인별 데이터 품질의 책임자 역할을 수행한다.

---

## Ⅰ. 개요 및 필요성

```text
+-------------------------------------------------------+
|    데이터 거버넌스 프레임워크                          |
+-------------------------------------------------------+
|  [전략] 데이터 전략·비전·원칙                        |
|  [조직] CDO · 데이터 스튜어드 · 거버넌스 위원회      |
|  [정책] 데이터 표준·품질 규칙·보안 정책·접근 제어    |
|  [프로세스] 메타데이터 관리·MDM·품질 모니터링        |
|  [기술] 데이터 카탈로그·리니지 추적·DQ 도구          |
+-------------------------------------------------------+
```

- **📢 섹션 요약 비유**: 데이터 거버넌스는 도시의 <strong>도로교통법</strong>이다. 차(데이터)가 많아지면 법(정책)·경찰(스튜어드)·신호등(기술)이 없으면 사고(데이터 오류)가 난다.

## Ⅱ. 아키텍처 및 핵심 원리

### DAMA-DMBOK 11대 영역

| 영역 | 설명 |
|:---|:---|
| <strong>데이터 거버넌스</strong> | 전사 의사결정 체계 |
| <strong>데이터 아키텍처</strong> | 데이터 모델·흐름 설계 |
| <strong>데이터 모델링</strong> | ERD·논리/물리 모델 |
| <strong>데이터 품질</strong> | 정확성·완전성·일관성 |
| <strong>메타데이터</strong> | 데이터에 대한 데이터 |
| <strong>데이터 보안</strong> | 접근 제어·암호화 |

- **📢 섹션 요약 비유**: DAMA-DMBOK는 데이터 관리의 <strong>백과사전</strong>이며, 거버넌스는 그 백과사전의 **총론** 챕터이다.

### 👶 어린이를 위한 3줄 비유 설명
1. 데이터 거버넌스는 도시의 <strong>교통법규</strong>예요. 차(데이터)가 많으면 법이 필요해요.
2. <strong>경찰(데이터 스튜어드)</strong>이 교통(데이터 품질)을 관리하고, <strong>신호등(기술 도구)</strong>이 흐름을 조절해요.
3. 법규가 없으면 사고(데이터 오류)가 나서 <strong>모두가 불편</strong>해진답니다!
