## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 역정규화 기법은 정규화된 스키마에서 **테이블 병합(Merge)·분할(Split)·중복 컬럼 추가(Redundancy)·파생 컬럼 추가(Derived)** 등의 구체적 물리 설계 패턴을 적용하여 읽기 성능을 최적화하는 실무 방법론이다.
> 2. **가치**: 역정규화 "개념"을 안다고 실전에서 바로 적용할 수 없다. <strong>어떤 상황에서 어떤 기법을 선택하는가(병합 vs 분할 vs 중복)</strong>의 판단 기준이 심화 학습과 실무 모두에서 핵심이다.
> 3. **판단 포인트**: 수평 분할은 <strong>Partition Key(연도·지역)</strong>로 스캔 범위를 줄이고, 수직 분할은 <strong>핫 컬럼과 콜드 컬럼</strong>을 분리하여 I/O를 최적화하며, 파생 컬럼은 <strong>집계 쿼리 제거</strong>에 효과적이다.

## Ⅰ. 개요 및 필요성

```text
+-------------------------------------------------------+
|    역정규화 5대 기법 한눈에 보기                       |
+-------------------------------------------------------+
|  [1] 테이블 병합: 1:1 관계 테이블 합치기              |
|      사원 + 사원상세 -> 사원통합                       |
|                                                       |
|  [2] 중복 컬럼 추가: FK 참조값을 복사                 |
|      주문(고객ID) + 고객(이름) -> 주문(고객명 복사)    |
|                                                       |
|  [3] 파생 컬럼 추가: 계산값 미리 저장                 |
|      주문상세(수량×단가) -> 주문(총액)                 |
|                                                       |
|  [4] 수평 분할: 행 기준 분리                          |
|      주문(10년치) -> 주문_2024, 주문_2025              |
|                                                       |
|  [5] 수직 분할: 열 기준 분리                          |
|      상품(이름,가격,설명,이미지) ->                    |
|      상품_핫(이름,가격) + 상품_콜드(설명,이미지)      |
+-------------------------------------------------------+
```

- **📢 섹션 요약 비유**: 역정규화 기법은 대형 마트 물류 최적화다. 병합은 인접 매대 통합, 수평 분할은 층별 분리, 수직 분할은 냉장·상온 구역 분리, 중복은 자주 찾는 상품을 여러 매대에 복사 배치.

## Ⅱ. 아키텍처 및 핵심 원리

### 기법별 선택 기준

| 기법 | 적용 조건 | 효과 | 부작용 |
|:---|:---|:---|:---|
| **병합** | 1:1 관계, 항상 함께 조회 | JOIN 제거 | 테이블 비대 |
| **중복 컬럼** | FK 참조값 빈번 조회 | JOIN 감소 | 동기화 필요 |
| **파생 컬럼** | SUM/COUNT 집계 빈번 | 집계 쿼리 제거 | 갱신 시 재계산 |
| <strong>수평 분할</strong> | 대용량+시간/지역 기반 조회 | 스캔 범위 축소 | 교차 파티션 조인 비용 |
| <strong>수직 분할</strong> | 핫/콜드 컬럼 명확 | I/O 감소 | 재조립 JOIN 필요 |

### 동기화 메커니즘

| 방식 | 적합 | 지연 |
|:---|:---|:---|
| <strong>DB 트리거</strong> | 실시간 동기화 필수 | 0 (즉시) |
| **배치 스크립트** | 일정 지연 허용 | 분~시간 |
| **앱 듀얼 라이트** | 코드 레벨 제어 | 0 (즉시) |

- **📢 섹션 요약 비유**: 트리거는 자동 분사 소화기(즉시 반응), 배치는 야간 청소(지연 허용), 듀얼 라이트는 수동 소화기(코드에서 직접 처리)이다.

| 비교 | 수평 분할 | 수직 분할 |
|:---|:---|:---|
| **기준** | 행(Row) | 열(Column) |
| **효과** | 스캔 범위 축소 | I/O 크기 축소 |
| **적합** | 시간/지역별 대용량 | 핫/콜드 컬럼 분리 |
| **예** | 주문_2024, 주문_2025 | 상품_기본, 상품_상세 |

## Ⅳ. 실무 적용 및 실무자 판단

### 학습 정리 구성
1. <strong>병목 식별</strong>: "주문 조회 API가 3-way JOIN으로 초당 5,000회 호출, 평균 200ms".
2. **기법 선택**: "중복 컬럼(고객명)을 주문 테이블에 추가하여 JOIN 제거".
3. <strong>동기화 설계</strong>: "고객명 변경 시 DB 트리거로 주문 테이블의 복사 컬럼을 자동 갱신".
4. **효과 측정**: "JOIN 제거 후 응답 시간 200ms -> 20ms, DB CPU 80% -> 30%".

## Ⅴ. 기대효과 및 결론

역정규화 기법은 "이론(정규화)과 실전(성능)"의 균형을 맞추는 <strong>DB 설계자의 핵심 역량</strong>이다. 최근 DB 레벨에서는 파티셔닝(수평 분할)이 표준 기능으로 내장되어 있고, CQRS + Event Sourcing으로 읽기 전용 역정규화 뷰를 이벤트 기반으로 자동 생성하는 패턴이 주류다.

### 👶 어린이를 위한 3줄 비유 설명
1. <strong>병합</strong>은 방 2개를 벽을 허물어 1개로 만드는 거예요 (찾으러 안 다녀도 됨).
2. <strong>분할</strong>은 큰 옷장을 여름옷·겨울옷 서랍으로 나누는 거예요 (찾기 빨라짐).
3. <strong>중복</strong>은 리모컨을 거실·안방에 1개씩 두는 거예요 (가까이서 바로 잡지만, 건전지를 2개 관리해야 해요)!
