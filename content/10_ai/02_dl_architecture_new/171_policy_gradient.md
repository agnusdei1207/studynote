## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정책 경사법 (Policy Gradient)은 행동가치 함수 `Q(s, a)`를 우회해, 정책 `πθ(a|s)` 자체를 파라미터화하고 기대 보상 `J(θ)`를 직접 최대화하는 강화학습 방법이다.
> 2. **가치**: 행동을 확률 분포로 다루기 때문에 연속 제어와 확률적 전략이 자연스럽고, "어떤 행동이 얼마나 자주 나와야 하는가"를 직접 설계할 수 있다.
> 3. **판단 포인트**: 순수 REINFORCE는 분산이 커서 실무 안정성이 낮으므로, 베이스라인·어드밴티지·액터-크리틱 (Actor-Critic)·PPO (Proximal Policy Optimization) 같은 분산 저감 장치와 함께 써야 한다.

---

## Ⅰ. 개요 및 필요성

정책 경사법은 상태를 입력받아 행동의 확률 분포를 바로 출력하는 강화학습 계열이다. 가치 기반 방법인 Q-러닝 (Q-Learning)이나 DQN (Deep Q-Network)은 각 행동의 점수를 계산한 뒤 최고 점수 행동을 고르는 구조라서, 행동 후보가 몇 개 안 되는 이산 공간에서는 강력하다. 그러나 로봇 관절 각도, 드론 추력, 자율주행 조향각처럼 연속적으로 변하는 행동 공간에서는 점수표를 전부 계산하는 방식이 금방 비효율적이 된다.

또 하나의 이유는 최적 행동이 항상 하나의 고정 답이 아닐 수 있다는 점이다. 포커, 경매, 다중 에이전트 게임처럼 상대가 내 패턴을 읽는 환경에서는 일부러 행동 확률을 섞는 혼합 전략이 필요하다. 정책 경사법은 이 확률 자체를 학습 대상으로 삼기 때문에, "가끔은 다른 행동을 해야 이긴다"는 문제를 더 직접적으로 다룬다.

아래 그림은 가치 기반과 정책 기반의 차이를 보여 준다.

```text
+----------------------------------------------------------------------+
| Value-based vs Policy-based decision                                 |
+------------------------------+--------------------------------------+
| state s                      | state s                              |
|   |                          |   |                                  |
|   v                          |   v                                  |
| Q(s,a1), Q(s,a2), ...        | πθ(a1|s), πθ(a2|s), ...             |
|   |                          |   |                                  |
| argmax action                | sample / choose from distribution    |
| best for finite actions      | natural for stochastic/continuous    |
+------------------------------+--------------------------------------+
```

즉 정책 경사법은 "점수표를 잘 맞히는 문제"에서 "행동 확률을 잘 조정하는 문제"로 초점을 바꾼다. 이 전환 덕분에 강화학습의 표현력은 커지지만, 대신 학습 신호의 분산을 어떻게 낮출지가 핵심 과제가 된다.

- **📢 섹션 요약 비유**: 가치 기반은 식당마다 점수를 매겨 항상 1등 가게만 가는 방식이고, 정책 경사법은 상황과 분위기에 따라 "오늘은 이 메뉴 70%, 저 메뉴 30%"처럼 선택 확률 자체를 조절하는 방식이다.

## Ⅱ. 아키텍처 및 핵심 원리

정책 경사법의 출발점은 정책을 파라미터 `θ`를 가진 신경망으로 두고, 기대 누적 보상 `J(θ)`를 최대화하는 것이다. 대표적인 기본형이 REINFORCE이며, 한 에피소드에서 얻은 궤적 `(s_t, a_t, r_t)`를 모은 뒤 각 시점의 할인 누적 보상 `G_t`를 계산해 정책을 업데이트한다. 실무 프레임워크에서는 보통 최대화 대신 손실 최소화를 쓰므로 `-log πθ(a_t|s_t) * G_t` 형태의 loss로 구현한다.

### 핵심 업데이트 직관

- 목적 함수: `J(θ) = E[Σ γ^t r_t]`
- 기본 업데이트: `θ <- θ + α Σ ∇θ log πθ(a_t|s_t) G_t`
- 분산 저감형: `θ <- θ + α Σ ∇θ log πθ(a_t|s_t) (G_t - b_t)`

여기서 `b_t`는 베이스라인 (Baseline)이다. 평균적인 기대치만큼은 빼고, 그보다 더 잘했는지 못했는지만 반영해 분산을 줄인다. 이 아이디어가 더 발전하면 어드밴티지 (Advantage)와 액터-크리틱 계열로 이어진다.

아래 그림은 학습 루프를 압축한 것이다.

```text
+----------------------------------------------------------------------+
| Policy Gradient training loop                                        |
+----------------------------------------------------------------------+
| state s_t --> policy πθ(a|s) --> sample action a_t                  |
|      ^                              |                                |
|      |                              v                                |
| next state s_{t+1} <-- environment reward r_t                       |
|                                                                      |
| trajectory {s,a,r} --> discounted return G_t                         |
|                               |                                      |
|                               +-> ∇θ log πθ(a_t|s_t) · G_t           |
|                                          |                           |
|                                          +- update θ                 |
+----------------------------------------------------------------------+
```

정책 네트워크의 출력 형태는 행동 공간에 따라 달라진다. 이산 행동이면 softmax 확률을, 연속 행동이면 가우시안 분포의 평균 `μ`와 표준편차 `σ`를 내보내는 식이 흔하다. 즉 정책 경사법은 단순히 "왼쪽/오른쪽"을 고르는 모델이 아니라, <strong>행동 분포의 모양 자체를 학습하는 모델</strong>이다.

| 행동 공간 | 정책 출력 예 | 장점 | 주의점 |
| :--- | :--- | :--- | :--- |
| 이산 행동 | softmax 확률 | 탐험과 활용을 한 분포로 표현 | 확률 붕괴 시 탐험 부족 |
| 연속 행동 | Gaussian `μ`, `σ` | 부드러운 제어 가능 | 범위 제한, 분산 튜닝 필요 |
| 제한된 연속 구간 | Beta 분포 등 | 행동 범위 내 샘플링 쉬움 | 구현 복잡도 증가 |

- **📢 섹션 요약 비유**: 정책 경사법은 시험이 끝난 뒤 "이번에 맞힌 답은 더 자주 쓰고, 틀린 답은 덜 쓰자"고 습관을 교정하는 방식이다. 정답표를 외우는 게 아니라, 선택하는 버릇 자체를 바꾸는 훈련이다.

## Ⅲ. 비교 및 연결

정책 경사법을 제대로 이해하려면 가치 기반, 순수 정책 기반, 그리고 그 절충형을 함께 봐야 한다. 같은 강화학습이라도 "무엇을 학습하느냐"가 다르기 때문이다.

| 구분 | 가치 기반 (DQN) | 정책 경사법 (REINFORCE) | 액터-크리틱 |
| :--- | :--- | :--- | :--- |
| 직접 학습 대상 | 행동가치 `Q(s,a)` | 정책 `πθ(a|s)` | 정책 + 가치함수 |
| 행동 공간 | 주로 이산 | 이산·연속 모두 가능 | 이산·연속 모두 가능 |
| 탐험 방식 | ε-greedy 등 별도 설계 | 정책 분포 내부에 내장 | 정책 분포 + 가치 평가 |
| 샘플 효율 | 비교적 좋음 | 낮은 편 | 중간 이상 |
| 핵심 위험 | 과대추정, moving target | 높은 분산 | 학습 불균형 |

순수 정책 경사법은 개념이 깔끔하지만, 좋은 보상을 얻은 긴 궤적 전체를 한꺼번에 칭찬하거나 벌하기 때문에 분산이 크다. 그래서 실제 연구와 산업에서는 가치함수를 함께 두는 액터-크리틱, 일반화된 어드밴티지 추정 (GAE, Generalized Advantage Estimation), PPO 같은 구조로 진화했다. 즉 현대 강화학습의 핵심은 정책 경사 철학을 유지하되, <strong>학습 신호를 얼마나 안정적으로 만들 것인가</strong>에 있다.

또한 연속 제어에서는 결정론적 정책 경사 (Deterministic Policy Gradient) 계열도 중요하다. DDPG (Deep Deterministic Policy Gradient), TD3 (Twin Delayed DDPG) 등은 정책 경사 사상을 유지하면서도 샘플 효율과 안정성을 보강한 변형으로 볼 수 있다.

- **📢 섹션 요약 비유**: 순수 정책 경사법은 감각은 뛰어나지만 기복이 큰 선수이고, 가치 기반은 계산은 정확하지만 움직임이 둔한 선수다. 액터-크리틱은 감각 좋은 선수 옆에 실시간 코치를 붙여 둘의 장점을 섞은 팀 전술에 가깝다.

## Ⅳ. 실무 적용 및 실무자 판단

정책 경사법은 로보틱스, 게임 AI, 자율 제어, 인간 선호 정렬 같은 영역에서 널리 쓰인다. 다만 실무에서는 "정책 경사법을 쓸 것인가"보다 "어떤 안정화 장치를 함께 둘 것인가"가 더 중요한 질문이다. 예를 들어 연속 제어에서 처음부터 순수 REINFORCE를 쓰는 경우는 드물고, 보통 PPO나 액터-크리틱 기반 알고리즘으로 출발한다.

### 실무 판단 체크리스트

1. 행동 공간이 연속적이거나, 확률적 정책 자체가 문제 정의에 중요한가?
2. 정책 출력이 실제 행동 범위와 맞는가? 예: 조향각 제한, 토크 상한, 확률 합 1.
3. 어드밴티지 정규화, 리워드 스케일링, 엔트로피 보너스 (Entropy Bonus) 같은 분산 제어 장치를 넣었는가?
4. KL 발산 (Kullback-Leibler Divergence), 정책 엔트로피, 평균 리턴을 함께 모니터링하고 있는가?
5. 서비스/제품 단계라면 순수 정책 경사법보다 PPO나 검증된 액터-크리틱 계열이 더 적합하지 않은가?

### 자주 발생하는 안티패턴

- 학습 중에도 항상 argmax만 사용해 정책 분포가 사실상 탐험하지 못하게 만드는 것
- 연속 행동에서 평균만 출력하고 분산을 고정하지 않아 행동 다양성이 사라지는 것
- 베이스라인 없이 긴 에피소드 전체를 한 번에 강화해 분산이 폭증하는 것
- 큰 학습률로 정책을 급격히 바꿔 정책 붕괴 (Policy Collapse)를 일으키는 것

언어 모델 정렬에서도 같은 철학이 보인다. RLHF (Reinforcement Learning from Human Feedback)는 사람 선호를 보상 신호로 바꿔 정책을 조정하는데, 이 역시 "행동 확률을 원하는 방향으로 밀어준다"는 점에서 정책 경사적 사고를 따른다. 다만 실제 시스템은 KL 제약, 보상 모델, 배치 안정성 같은 추가 안전장치가 필수다.

- **📢 섹션 요약 비유**: 정책 경사법을 실전에 쓰는 일은 본능 좋은 신입 사원에게 바로 전권을 주는 일이 아니다. 좋은 피드백 체계, 행동 범위, 평가 기준을 함께 붙여야 본능이 실력으로 바뀐다.

## Ⅴ. 기대효과 및 결론

정책 경사법의 가장 큰 효과는 강화학습이 직접 행동 분포를 다루게 했다는 점이다. 덕분에 확률적 전략, 연속 제어, 미세 조정이 필요한 문제를 한 프레임 안에서 설명할 수 있게 됐다. 특히 "무엇을 할 것인가"뿐 아니라 "얼마나 자주 그렇게 할 것인가"를 학습한다는 점이 가치 기반 접근과의 본질적 차이다.

반면 비용도 있다. 샘플 효율이 낮고, 보상 설계에 민감하며, 분산과 안정화 문제가 늘 따라온다. 그래서 현대 실무에서는 정책 경사법을 단독 알고리즘이라기보다, PPO (Proximal Policy Optimization), A2C (Advantage Actor-Critic), A3C (Asynchronous Advantage Actor-Critic), SAC (Soft Actor-Critic) 같은 계열의 출발 철학으로 보는 것이 더 정확하다.

결론적으로 정책 경사법은 <strong>행동 점수표를 간접적으로 맞히는 대신, 행동 확률 자체를 직접 훈련하는 강화학습 원리</strong>로 기억하면 된다. 이 원리를 이해하면 왜 연속 제어와 인간 선호 정렬에서 정책 기반 계열이 강한지 자연스럽게 연결된다.

- **📢 섹션 요약 비유**: 정책 경사법은 정답 노트를 외우는 공부가 아니라, 상황을 보고 적절한 선택이 몸에 배도록 습관을 훈련하는 공부법이다. 잘만 다듬으면 복잡한 상황에서도 몸이 먼저 자연스럽게 반응한다.

### 📌 관련 개념 맵

| 개념 | 연결 포인트 |
| :--- | :--- |
| 정책 (Policy) | 상태를 행동 확률 분포로 바꾸는 직접 대상 |
| 가치 함수 (Value Function) | 베이스라인과 액터-크리틱으로 이어지는 보조 평가 기준 |
| 어드밴티지 (Advantage) | 평균 수준 대비 얼마나 더 잘했는지 계산해 분산을 낮춤 |
| 엔트로피 보너스 (Entropy Bonus) | 정책이 너무 빨리 확정되지 않도록 탐험성을 유지 |
| 액터-크리틱 (Actor-Critic) | 정책 경사와 가치 추정을 결합한 안정화 구조 |
| PPO (Proximal Policy Optimization) | 정책 업데이트 폭을 제한해 실무 안정성을 높인 대표 계열 |


### 👶 어린이를 위한 3줄 비유 설명

1. 정책 경사법은 로봇이 "이럴 때는 이런 행동을 해 볼 확률"을 몸으로 배우는 연습이에요.
2. 잘된 행동은 다음에 더 자주 하도록 하고, 잘못된 행동은 덜 하도록 습관을 조금씩 고쳐요.
3. 그래서 정답표를 외우지 않아도, 비슷한 상황이 오면 몸이 자연스럽게 좋은 선택을 하게 돼요.
