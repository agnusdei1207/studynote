## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 단층 퍼셉트론(Single-Layer Perceptron)은 하나의 선형 결정 경계로 입력을 분류하는 가장 단순한 신경망이다.
> 2. **가치**: XOR(배타적 논리합)은 선형 분리 불가능 문제라서 단층 퍼셉트론만으로는 풀 수 없고, 이 한계가 다층 신경망의 필요성을 보여준다.
> 3. **판단**: 활성화 함수, 특징 변환, 은닉층(Hidden Layer)의 역할을 이해해야 퍼셉트론의 한계를 정확히 설명할 수 있다.

---

## Ⅰ. 개요 및 필요성

퍼셉트론은 인공지능 초기 역사에서 "기계가 학습할 수 있다"는 희망을 보여준 모델이다. 그러나 모든 문제를 직선 하나로 나눌 수는 없다는 사실이 XOR에서 드러났다.

이 문제는 단순한 수학 문제가 아니라, 왜 다층 신경망과 역전파(Backpropagation)가 필요해졌는지를 설명하는 대표 사례다.

- **📢 섹션 요약 비유**: 한 줄 테이프로만 모든 장난감을 분류하려다 보니, 대각선으로 놓인 두 개는 절대 같이 못 나눈다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
x1, x2
  v
w1, w2, b
  v
z = w1x1 + w2x2 + b
  v
Activation
  v
0 or 1
```

| 요소 | 역할 |
| :-- | :-- |
| Input | 특징값 입력 |
| Weight | 입력의 중요도 조절 |
| Bias | 결정 경계 이동 |
| Activation | 선형 결과를 이진 출력으로 변환 |

단층 퍼셉트론은 직선 또는 초평면 하나로 구분 가능한 문제에만 강하다. XOR처럼 같은 출력이 대각선으로만 모이는 문제는 선형 경계 하나로 나눌 수 없다.

- **📢 섹션 요약 비유**: 자로 그은 한 줄로는 바둑판의 대각선만 따로 떼기 어렵다.

---

## Ⅲ. 비교 및 연결

| 문제 | 선형 분리 가능 여부 | 단층 퍼셉트론 |
| :-- | :-- | :-- |
| AND | 가능 | 해결 가능 |
| OR | 가능 | 해결 가능 |
| XOR | 불가능 | 해결 불가 |

| 모델 | 특징 | 한계 |
| :-- | :-- | :-- |
| 단층 퍼셉트론 | 빠르고 단순 | 선형 문제만 가능 |
| 다층 퍼셉트론(MLP) | 은닉층으로 비선형 표현 | 학습이 복잡 |

XOR 문제는 "퍼셉트론이 틀렸다"는 뜻이 아니라, 표현력이 더 필요한 문제라는 뜻이다. 이 한계가 곧 신경망 발전의 출발점이 됐다.

- **📢 섹션 요약 비유**: 직선 자로 못 그리면 곡선 자가 필요하다는 사실을 처음 알려준 사례다.

---

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 문제가 선형 분리 가능한지 먼저 확인했는가?
2. 특징 변환으로 선형화할 수 있는가?
3. 활성화 함수와 손실 함수의 역할을 알고 있는가?
4. 은닉층이 왜 필요한지 설명할 수 있는가?
5. XOR 사례를 통해 모델 한계를 설명할 수 있는가?

### 안티패턴

- 단층 퍼셉트론으로 모든 분류 문제를 풀 수 있다고 믿는 설계
- XOR을 단순한 예제로만 보고 본질을 놓치는 설명
- 선형 분리 불가능 문제에 특징 변환 없이 고집하는 설계
- 활성화 함수 없이 선형 조합만 쓰는 설계

실무 관점에서는 XOR을 "실패 사례"가 아니라 "표현력 한계의 증거"로 이해해야 한다. 모델의 한계를 정확히 말해야 적절한 아키텍처를 고를 수 있다.

- **📢 섹션 요약 비유**: 두 점이 엇갈려 있으면 단순한 울타리 하나로는 못 나누니, 안쪽 울타리가 더 필요하다.

---

## Ⅴ. 기대효과 및 결론

단층 퍼셉트론과 XOR 문제는 딥러닝 이전의 한계를 보여 주는 상징적 사례다. 이 사례를 이해하면 왜 비선형성과 은닉층이 중요한지 자연스럽게 보인다.

결국 중요한 것은 "모델이 얼마나 단순한가"가 아니라 "문제를 표현할 수 있는가"다.

- **📢 섹션 요약 비유**: 직선 하나로 안 되면 접힌 종이처럼 여러 겹의 표현이 필요하다.
