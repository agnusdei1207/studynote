## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 가중치(Weight)와 편향(Bias)은 신경망이 입력을 출력으로 변환할 때 사용하는 선형 방정식의 핵심 파라미터다.
> 2. **가치**: Weight는 입력의 중요도를 조정하고, Bias는 결정 경계를 이동시킨다.
> 3. **판단**: 이 둘을 이해해야 퍼셉트론, MLP, DNN의 동작과 학습의 의미를 설명할 수 있다.

---

## Ⅰ. 개요 및 필요성

신경망은 복잡해 보여도 기본은 선형 결합이다. `y = Wx + b`는 모든 시작점이 되는 가장 단순한 식이다.

Weight와 Bias를 이해하면 모델이 왜 어떤 입력에는 민감하고 어떤 입력에는 둔감한지 설명할 수 있다.

- **📢 섹션 요약 비유**: 요리에서 소금이 많으면 맛이 진해지고, 물의 양을 바꾸면 전체 맛이 이동하는 것과 같다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
x --(W)--> sum --(+ b)--> activation --> output
```

| 파라미터 | 역할 |
| :-- | :-- |
| Weight (W) | 입력의 영향력 조절 |
| Bias (b) | 기준점 이동 |

Weight는 입력값을 얼마나 크게 볼지 결정하고, Bias는 결과가 0이 되는 위치를 좌우로 옮긴다. 이 둘이 함께 있어야 선형 모델이 유연해진다.

- **📢 섹션 요약 비유**: 그네의 힘과 출발 위치를 같이 정하는 것과 같다.

---

## Ⅲ. 비교 및 연결

| 구분 | Weight | Bias |
| :-- | :-- | :-- |
| 역할 | 기울기/중요도 | 절편/오프셋 |
| 학습 | 데이터에 맞춰 조정 | 경계 위치 보정 |
| 영향 | 특징별 가중 | 전체 이동 |

| 모델 | 표현 |
| :-- | :-- |
| Perceptron | 선형 분류 |
| MLP | 비선형 표현의 기본 구성 |
| DNN | 많은 층에서 반복 사용 |

Weight와 Bias는 신경망에서 가장 기본적이면서도 중요한 학습 대상이다. 이 둘이 어떻게 움직이는지 보면 모델의 결정을 이해할 수 있다.

- **📢 섹션 요약 비유**: 문턱 높이를 바꾸고, 문을 밀어 여는 힘을 바꾸는 셈이다.
