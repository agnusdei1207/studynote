## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 활성화 함수는 신경망의 선형 결합 결과에 비선형성을 넣어 표현력을 높이는 함수다.
> 2. **가치**: 활성화 함수가 없으면 깊은 신경망도 결국 하나의 선형 모델로 붕괴된다.
> 3. **판단**: 함수 선택은 성능, 기울기 소실, 계산 비용을 함께 고려해야 한다.

---

## Ⅰ. 개요 및 필요성

신경망은 입력을 단순히 더하는 것만으로는 복잡한 패턴을 배울 수 없다. 비선형성이 있어야 학습이 가능해진다.

활성화 함수는 뉴런이 다음 층으로 신호를 보낼지, 얼마나 보낼지 결정한다.

- **📢 섹션 요약 비유**: 스위치를 켤지 말지 결정하는 문지기다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Weighted Sum
  v
Activation Function
  v
Non-linear Output
```

| 함수 | 특징 |
| :-- | :-- |
| Sigmoid | 0~1, 확률 해석 가능 |
| Tanh | -1~1, 중심화 |
| ReLU | 단순하고 빠름 |
| Softmax | 분류 출력 |

활성화 함수는 선형 조합을 비선형 변환으로 바꾼다. 그래서 층을 많이 쌓아도 표현력이 유지된다.

- **📢 섹션 요약 비유**: 같은 재료라도 굽고 익히면 다른 맛이 난다.

---

## Ⅲ. 비교 및 연결

| 함수 | 장점 | 단점 |
| :-- | :-- | :-- |
| Sigmoid | 확률적 해석 | 기울기 소실 |
| Tanh | 중심화 | 포화 영역 |
| ReLU | 단순/빠름 | 죽은 뉴런 |
| Softmax | 분류에 적합 | 출력층 전용 |

| 역할 | 의미 |
| :-- | :-- |
| Non-linearity | 복잡한 경계 학습 |
| Gradient Flow | 학습 안정성 |

활성화 함수는 신경망의 성질을 바꾸는 핵심 요소다. 어떤 함수를 쓰느냐가 학습 속도와 성능을 크게 좌우한다.

- **📢 섹션 요약 비유**: 문을 열 때 손잡이 모양이 다르면 힘 주는 방식도 달라진다.

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 문제에 맞는 활성화 함수를 선택했는가?
2. 기울기 소실과 폭주를 고려했는가?
3. 출력층과 은닉층의 함수를 구분하는가?
4. 계산 비용과 성능을 함께 봤는가?
5. ReLU 계열의 장단을 아는가?

### 안티패턴

- 활성화 함수를 생략하는 설계
- 모든 층에 같은 함수를 무작정 쓰는 설계
- 포화 구간과 죽은 뉴런을 무시하는 설계
- 출력층 함수와 손실 함수를 혼동하는 설계

실무 관점에서는 활성화 함수를 "비선형성을 넣는 장치"로 명확히 설명해야 한다.

- **📢 섹션 요약 비유**: 직선만 그리면 그림이 단조롭고, 꺾임이 있어야 형태가 살아난다.

---

## Ⅴ. 기대효과 및 결론

활성화 함수는 신경망이 복잡한 패턴을 학습하게 하는 필수 요소다. 그래서 DNN의 성패에 직접 영향을 준다.

결론적으로 활성화 함수는 신경망의 비선형 엔진이다.

- **📢 섹션 요약 비유**: 불을 켜고 끄는 스위치가 있어야 기계가 일한다.
