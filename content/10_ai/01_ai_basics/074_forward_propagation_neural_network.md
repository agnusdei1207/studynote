## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 순전파는 입력이 신경망의 각 층을 지나 출력으로 계산되는 과정이다.
> 2. **가치**: 예측값을 만들고 손실을 계산하는 출발점이다.
> 3. **판단**: 가중치와 활성화 함수가 층마다 적용된다.

---

## Ⅰ. 개요 및 필요성

신경망은 입력을 그냥 내보내지 않는다. 여러 층을 거쳐 계산한다.

그 계산 흐름이 순전파다.

- **📢 섹션 요약 비유**: 공을 여러 사람에게 차례로 넘기는 것과 같다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Input
  v weighted sum
Activation
  v
Output
```

| 요소 | 의미 |
| :-- | :-- |
| Weight | 가중치 |
| Bias | 편향 |
| Activation | 비선형 함수 |

순전파는 각 층에서 선형 결합 후 활성화를 거쳐 다음 층으로 전달된다.

- **📢 섹션 요약 비유**: 여러 필터를 차례로 통과하는 물건이다.

---

## Ⅲ. 비교 및 연결

| 단계 | 역할 |
| :-- | :-- |
| Forward | 계산 |
| Loss | 오차 |
| Backward | 역전파 |

| 관련 | 의미 |
| :-- | :-- |
| Neural Network | 구조 |
| Prediction | 출력 |

순전파는 역전파와 짝을 이뤄 학습을 완성한다.

- **📢 섹션 요약 비유**: 앞으로 보내고 뒤로 돌아오며 배우는 과정이다.

---

## Ⅳ. 실무 적용 및 실무자 판단

### 체크리스트

1. 입력->은닉->출력 흐름을 아는가?
2. 가중치와 편향을 이해하는가?
3. 활성화 함수의 역할을 아는가?
4. 손실 계산과 연결하는가?
5. 역전파와 구분하는가?

### 안티패턴

- 순전파와 역전파를 혼동하는 설계
- 선형 결합만 보고 끝나는 설계
- 활성화 함수를 무시하는 설계
- 층별 계산을 대충 보는 설계

실무 관점에서는 순전파를 "신경망의 예측 계산 흐름"으로 설명해야 한다.

- **📢 섹션 요약 비유**: 입력이 순서대로 계산되어 결과가 나온다.

---

## Ⅴ. 기대효과 및 결론

순전파는 신경망이 예측값을 내는 기본 과정이다.

결론적으로 순전파는 입력이 층을 통과하며 출력이 되는 계산 흐름이다.

- **📢 섹션 요약 비유**: 공이 앞으로 넘어가며 결과가 만들어진다.
